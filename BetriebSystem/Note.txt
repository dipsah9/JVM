Here we used getpwnam() functions to retrieve the password file entry for the logged in users from the system 
database. 
struct passwd contains the following contents: 
char *pw_uid   : gives the user id 
char *pw_passwd: give the password
char * pw_gid  : uses for the group id 
char * pw_gecos: used for the user Description
char * pw_dir  : return the home directory 
char * pw_shell: User's default shell
